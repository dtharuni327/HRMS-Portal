# Product Scope Cut

## Why Scope Must Be Cut

The SOW covers a multi-phase enterprise product. In 2 days, the team can only deliver a high-confidence MVP.

## Final MVP Scope

### Module 1: Attendance

Include:

- Punch in
- Punch out
- Work mode selection
- Working hours calculation
- Late mark flag
- Holiday display
- Leave balance display

Defer:

- Full GPS verification workflow
- Location spoof detection
- Random location checks
- Complex project time splitting

### Module 2: Payroll

Include:

- CTC entry
- Monthly and daily salary computation
- Salary preview
- LOP deduction basics
- Payslip PDF generation

Defer:

- Tax regime optimization
- Reimbursement processing
- Salary advances
- Full finance integration

### Module 3: Employee Management

Include:

- Employee onboarding
- Profile management
- Manager assignment
- Department and designation mapping
- Document metadata and upload placeholders

Defer:

- Full verification workflows
- Expiry alerts
- Offer and appointment letter automation

### Module 4: Dashboards

Include:

- Employee dashboard
- Manager dashboard
- HR dashboard
- Admin dashboard

Defer:

- Advanced analytics
- Attrition prediction
- System health deep views

### Module 5: Communication

Include:

- Announcements
- Basic notification placeholders

Defer:

- Real-time chat
- Group messaging
- Helpdesk

### Module 6: AI

Defer entire module for post-handover roadmap.

### Module 7: Advanced Features

Defer entire module except simple reports if time allows.

## Acceptance Criteria

The MVP is acceptable if the client can:

- Create and log in as different user roles
- Manage employees
- Record attendance
- Request and approve leave
- View basic payroll calculations
- Download a payslip
- Review dashboards and announcements

Phase 3:

Phase 4:
